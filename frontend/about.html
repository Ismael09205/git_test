About ShopEasy

ShopEasy is a simple demo e-commerce app built with plain HTML, CSS, and JavaScript on the frontend and Node.js + Express on the backend.

Tech stack

Layer Technology
FrontendHTML · CSS · Vanilla JS
BackendNode.js · Express
StorageIn-memory (demo only)

Features

  • Browse products with category filters
  • Add items to cart and adjust quantities
  • Checkout form and order placement
  • Order history page
